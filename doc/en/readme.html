Sound Themes for NVDA

Version 0.11.0: More complete typing sounds and removable presets

When Typing Sounds is enabled, Enter, Space, Backspace and Delete are now detected on their first physical keydown in a focused editable text control, even when NVDA does not report them through its typed-character event. A matching later event is suppressed to avoid hearing two clicks. Each selected typing pack uses its own distinct Enter/Space/Backspace WAV if provided; otherwise it plays a real character-typing WAV from the same pack. The 13 built-in typing packs do not all contain separate recordings: 11 lack a dedicated Enter, four lack Space and five lack Backspace. No synthetic recordings were added. Keyboard Sounds mode retains its separate physical-key assignments.

The Import old sounds folder... button has been removed. In Manage sound themes, every preset can now be removed, including all bundled presets and the last item in any category. Removing a bundled preset hides it persistently across add-on updates and can be undone through Restore removed presets...; deleting a personal pack deletes its files after confirmation. Built-in packs may still be copied to edit their WAVs. No theme is compulsory and no empty default theme is generated.

Version 0.10.0: Fix the unwanted Shift speech-pause sound; explain every event

NVDA sends a speech-pause notification when Shift pauses speech. The previous add-on responded by playing the separate Speech feedback paused recording, even if Navigation sounds were disabled, because it was a System sound. That is why Shift could sound twice. Play speech-pause feedback is now off by default and physical Shift presses are excluded even if you enable it. Your assigned physical Shift key sound still works when Keyboard Sounds is on. The paused-feedback WAV remains available for manual preview and reassignment.

Inside Edit sounds, arrow through an event to preview its recording. An accessible Description of selected sound event text box explains when the event happens, with examples such as a file in File Explorer, a folder tree, a browser tab or an NVDA speech event. The Speak the event description when moving through the list option is enabled by default; the description is read after a brief pause and superseded descriptions are cancelled when you move quickly. Tab to the read-only text box to read it in full. Names in the list remain short, so typing C still jumps to a C item. Some legacy sounds have no reliable automatic NVDA trigger; descriptions identify these explicitly.

Version 0.9.0: Complete original effects pack and single Shift cue

When Windows or a keyboard driver delivers both a generic Shift key and a left/right Shift code, Sound Themes treats these as one held physical key and plays a single assigned recording. Control and Alt aliases are treated the same way. This does not silence sounds from unrelated running add-ons or Windows itself.

The newly supplied original effects.zip adds a complete default navigation sound set (85 distinct mapped events from 86 source files), and fills 59 missing NVDA events in the previously selected VoiceOver pack while preserving the existing ScreenReaderSounds priority. Eleven extra typing themes are available, plus the original Classic Typewriter bell. There are now 706 genuine PCM WAV files across 23 built-in folders. No synthetic sounds or theme.json files are installed. The real NVDA roles/states available depend on the NVDA version and the applications being used.

Version 0.8.0: Instant sound previews on selection

Arrow through a Navigation, Typing or Keyboard sound pack list to hear a genuine sample from the highlighted pack, without activating it. Arrow through the event editor to hear that event's assigned WAV. Empty entries are silent. Previews load off the dialog thread; when navigation changes before decoding finishes, old pending previews are ignored.

Pack names now begin directly with the name, such as Cherry instead of "Built-in: Cherry", so typing C selects Cherry. The event list also omits redundant role/state type prefixes and assignment suffixes; keyboard letters are listed as A, B, C, etc. Category controls remain separate.

Up to twelve independent NVDA audio streams play at once: long navigation and typing recordings no longer interrupt or delay other sounds. Playback has a bounded queue to avoid accumulating sounds long after focus moves. Keyboard Sounds remains mutually exclusive with Navigation and Typing, as before. Bundled effects are stored directly under globalPlugins/soundThemes/effects/; personal themes stay in the NVDA configuration folder so upgrades do not erase them.

There are three sound modes. Navigation and Typing are enabled by default, while Keyboard Sounds is disabled. Enabling Keyboard Sounds automatically turns off BOTH Navigation and Typing. Turning either of those back on disables Keyboard Sounds. Lock/unlock sounds stay under the independent System option.

Navigation sounds respond to actual NVDA focus, roles, browse, caret and selection changes. With Keyboard Sounds disabled, merely pressing Tab, arrows, Home, End or Page Up/Down does not make a keypress sound. Keyboard Sounds uses exactly one assigned WAV for each physical key, with NO random playback.

Settings now has one Manage sound themes button opening Navigation, Typing and Keyboard Sounds tabs, and one Open sound folders button for the three directories. In the keyboard theme editor, focus the Capture and preview a physical key field and press a key to select its event and immediately preview any assigned WAV. Outside that field, Tab and Escape retain normal dialog behavior. Use Replace WAV to choose any PCM WAV from your computer: its filename is automatically changed to the canonical key name, e.g. keyboard.f7.wav.

Keyboard packs live in globalPlugins/soundThemes/effects/keyboard/<pack>/ or soundThemes/effects/keyboard/<pack>/ in NVDA's user configuration. The keyboard/voiceover pack has three original ScreenReaderSounds recordings (Backspace, End and Shift+Tab). Seven other original Kliq sound packs are included: Cherry, DSA, KAT, MT3, OEM, SA and XDA. The new-install keyboard theme defaults to KAT. Unrecorded special keys use an original, non-random sound from the SAME keyboard pack; personal themes without a fallback remain silent for missing keys.

Original ScreenReaderSounds audio has NOW been imported from the 17 MB WAV-bearing ZIP, including its inner objdata.zip role sounds and three OGGs decoded to real WAV. The integrated add-on contains 706 actual WAV recordings across navigation, typing and keyboard; none are synthetic. Key-release sounds are not installed because this add-on only plays key-down sounds. Explorer selected items now play their genuine listitem/treeviewitem sounds, and rapid focus changes cancel stale buffered audio so cues follow the current item. Some hardware Fn/brightness keys are not visible to NVDA and cannot be guaranteed. See KEYBOARD_SOUNDS_GUIDE.md and PROJECT_STATUS.md in the source distribution.

Using and editing sound themes

Customize sound effects for focus, typing, navigation, object roles and states, Windows lock and unlock, plus many other NVDA events.

Set up

  1. After installing the add-on, restart NVDA.
  2. Open NVDA menu, Preferences, Settings, Sound Themes.
  3. Select navigation and typing sound themes independently, then customize volume and event options.
  4. Choose Manage sound themes and then its Navigation or Typing tab. Copy a built-in theme to edit it, then assign WAV files to individual events using the keyboard-friendly event list. Each manager lists only that kind of sound event. You may add multiple variations to one event; randomized typing plays WAV files only from the currently selected typing theme.

Sound folders

Included sound packs reside in globalPlugins/soundThemes/effects/navigation/ and globalPlugins/soundThemes/effects/typing/. Each pack folder contains WAV files directly, with no theme.json or manifest. For example, role.button.wav, key.tab.wav, system.lock.wav, and system.secure_enter.wav identify events. Files named key.character.wav and key.character__1.wav provide random typing variations, drawn exclusively from the active typing pack. The two included navigation packs are navigation/voiceover (109 events) and navigation/default (85 events); the typing/classic-typewriter pack now includes six original character variations plus a real carriage bell. Eleven more typing themes were added in version 0.9. The earlier code-only ZIP did not include audio; a newer genuine sound-bearing ScreenReaderSounds ZIP has since been imported, as described above. No synthesized WAVs are bundled. Custom packs use soundThemes/effects/navigation/ and soundThemes/effects/typing/ under the NVDA user configuration directory. Existing v0.1.0 personal themes are copied into the two new categories without removing the original files. Personal v0.2.0 packs are converted with backups of the original folders.

Shortcuts

  • NVDA+Alt+N: toggle navigation effects, twice to toggle typing effects.
  • NVDA+Alt+O: toggle all sound effects.
  • NVDA+Alt+Z and NVDA+Alt+X: cycle between navigation themes only.

Notes

The old folder-import button was removed; use Import theme ZIP or select Replace WAV to set sound files in a personal pack. Custom themes are stored under the NVDA configuration path and survive add-on updates. Use PCM WAV audio. Lock and unlock effects use NVDA's session-state events; secure-desktop transitions use a separate listener when the running NVDA version provides one. Keyboard context is captured through NVDA's existing raw-key hook, retaining the useful pressed-key tracking provided by the old k library without installing an additional global keyboard hook. Running any add-on on Windows secure screens must be explicitly permitted through NVDA's system-wide configuration feature and entails security risks.

This preview has passed the offline regression suite but has not been verified end-to-end on Windows NVDA 2026. The first 21 WAVs came from the original navSounds publisher; the new audio-bearing ScreenReaderSounds ZIP provided the additional recordings, and seven Kliq themes were supplied by the user. The packaged total is now 706 original WAVs. Kliq recordings are MIT licensed; the notice is included as doc/KLIQ_LICENSE.txt. See SOUND_SOURCES.md in the source distribution.
