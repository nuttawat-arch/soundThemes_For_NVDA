Sound Themes for NVDA

Version 0.15.0: Direct Tools-menu settings and private GitHub updates

Open NVDA menu → Tools → Sound Themes settings... to reach all options, presets and sound editors. Sound Themes is no longer a nested panel in NVDA Preferences → Settings. The standalone window provides OK and Cancel. It also includes Check for Sound Themes updates when NVDA starts and Check for updates now. After startup, an optional background check looks for a newer stable installer in the project's official GitHub Releases; when found you may update now, wait, or skip that version. NVDA confirms installation and restart. No NVDA Add-on Store submission is needed. Export custom presets before an update, because their WAVs are stored inside the installed add-on. The author's private release.ps1 automates tagging and GitHub Releases; it is excluded from both download packages.

iPhone Keyboard and VoiceOver Typing use separately supplied PCM recordings. They may sound similar, but comparison confirms their corresponding WAVs and waveforms are not identical. Both editable presets remain available.

Version 0.14.0: Two keyboard layers, editable sound packs and a faster experience

Keyboard Sounds has exactly two per-preset playback choices: Separate press/release WAVs (two layers) or Combined press-and-release in one WAV (one layer, played once on keydown). Old press-only configuration values are mapped to combined to avoid changing which key events sound. Repeated held keys and duplicate modifier key events are filtered; no extra delay has been inserted into typing. When Navigation is disabled the browser virtual-caret listener skips its expensive cursor inspection, even if Keyboard Sounds is active.

All Navigation, Typing and Keyboard presets—including supplied ones—can be directly edited, renamed and deleted. The editor displays one alphabetically sorted event list with familiar short names such as checkbox and editabletext, accepting corresponding bare-name WAVs. Done saves edits; Cancel or closing the editor restores its previous WAV assignments. The sound folder is now exclusively inside the add-on: globalPlugins/soundThemes/effects/. A previous external user-config sound directory is only read for safe one-time migration and is never recreated. Export customized packs as ZIP files before an NVDA add-on update: replacing the installed add-on may overwrite WAV edits stored inside it.

The newly supplied ScreenReaderSounds audio has added real TalkBack navigation and typing presets and one new VoiceOver navigation event. Where ScreenReaderSounds and NavigationSounds supply the same event, ScreenReaderSounds has priority. The add-on packages 1,398 genuine WAVs in 26 editable presets. Existing Navigation and Typing behaviors are retained; live Windows/NVDA browser and key-event verification is still necessary.

Version 0.13.0: Per-preset keyboard press and release

Historically, v0.13 introduced press-only, separate press/release and combined key audio. As of v0.14, press-only is folded into the one-file combined mode, leaving only the two options described above. NVDA's existing raw-key extension point detects presses and releases, without another system-wide keyboard hook or interfering with shortcuts. Holding a key does not repeatedly play its press sound. Physical left/right Shift, Ctrl and Alt remain distinct, as do Return and Numpad Enter.

The keyboard editor has Replace/Preview/Remove release WAV controls. The press recording uses keyboard.a.wav; the optional release is keyboard.a__release.wav. Each preset's mode is saved in user config and remains intact across updates, copies and ZIP export/import. The existing Navigation and Typing behavior and user presets are retained. All seven Kliq keyboard themes now include their original key-release sounds. New Bucklespring adds 209 original press/release recordings: in its source NN-1.wav means press and NN-0.wav means release. See the included Bucklespring GNU GPL v2 license. Test live key behavior on Windows NVDA to confirm keyboard drivers expose all desired transitions.

Version 0.12.0: Restored button, link and heading sounds in web Browse Mode

The two included Navigation presets already have real WAV recordings for web buttons, links, headings, checkboxes, radio options and menu commands. The previous problem was how events were detected. In NVDA Browse Mode the virtual cursor can move to website controls without moving keyboard focus, so normal focus-change events cannot provide all sounds. The former Browse Mode integration also addressed the wrong extension-point location, while its backup Quick Navigation wrapper accidentally invoked the wrong function after initialization.

The add-on now detects actual virtual cursor movement using reversible NVDA Browse Mode hooks. Moving through a page using single-letter commands such as B (button), K (link), H (heading), or arrow navigation plays one appropriate sound from the currently selected Navigation pack. When text belongs to a focusable link/button, its accessible ancestor is preferred; otherwise a real caret cue is used if no identifiable control exists. The original recordings remain unchanged. Turning off Navigation mutes these sounds; Keyboard Sounds retains its existing independent behavior. Please verify on Windows with NVDA Browse Mode enabled in Chrome, Firefox or Edge.

Version 0.11.0: More complete typing sounds and removable presets

When Typing Sounds is enabled, Enter, Space, Backspace and Delete are now detected on their first physical keydown in a focused editable text control, even when NVDA does not report them through its typed-character event. A matching later event is suppressed to avoid hearing two clicks. Each selected typing pack uses its own distinct Enter/Space/Backspace WAV if provided; otherwise it plays a real character-typing WAV from the same pack. The 13 built-in typing packs do not all contain separate recordings: 11 lack a dedicated Enter, four lack Space and five lack Backspace. No synthetic recordings were added. Keyboard Sounds mode retains its separate physical-key assignments.

The Import old sounds folder... button has been removed. In Manage sound themes, every preset can now be removed, including all bundled presets and the last item in any category. Removing a bundled preset hides it persistently across add-on updates and can be undone through Restore removed presets...; deleting a personal pack deletes its files after confirmation. Built-in packs may still be copied to edit their WAVs. No theme is compulsory and no empty default theme is generated.

Version 0.10.0: Fix the unwanted Shift speech-pause sound; explain every event

NVDA sends a speech-pause notification when Shift pauses speech. The previous add-on responded by playing the separate Speech feedback paused recording, even if Navigation sounds were disabled, because it was a System sound. That is why Shift could sound twice. Play speech-pause feedback is now off by default and physical Shift presses are excluded even if you enable it. Your assigned physical Shift key sound still works when Keyboard Sounds is on. The paused-feedback WAV remains available for manual preview and reassignment.

Inside Edit sounds, arrow through an event to preview its recording. An accessible Description of selected sound event text box explains when the event happens, with examples such as a file in File Explorer, a folder tree, a browser tab or an NVDA speech event. The Speak the event description when moving through the list option is enabled by default; the description is read after a brief pause and superseded descriptions are cancelled when you move quickly. Tab to the read-only text box to read it in full. Names in the list remain short, so typing C still jumps to a C item. Some legacy sounds have no reliable automatic NVDA trigger; descriptions identify these explicitly.

Version 0.9.0: Complete original effects pack and single Shift cue

When Windows or a keyboard driver delivers both a generic Shift key and a left/right Shift code, Sound Themes treats these as one held physical key and plays a single assigned recording. Control and Alt aliases are treated the same way. This does not silence sounds from unrelated running add-ons or Windows itself.

The newly supplied original effects.zip adds a complete default navigation sound set (85 distinct mapped events from 86 source files), and fills 59 missing NVDA events in the previously selected VoiceOver pack while preserving the existing ScreenReaderSounds priority. Eleven extra typing themes are available, plus the original Classic Typewriter bell. There are now 706 genuine PCM WAV files across 23 built-in folders. No synthetic sounds or theme.json files are installed. The real NVDA roles/states available depend on the NVDA version and the applications being used.

Version 0.8.0: Instant sound previews on selection

Arrow through a Navigation, Typing or Keyboard sound pack list to hear a genuine sample from the highlighted pack, without activating it. Arrow through the event editor to hear that event's assigned WAV. Empty entries are silent. Previews load off the dialog thread; when navigation changes before decoding finishes, old pending previews are ignored.

Pack names now begin directly with the name, such as Cherry instead of "Built-in: Cherry", so typing C selects Cherry. The event list also omits redundant role/state type prefixes and assignment suffixes; keyboard letters are listed as A, B, C, etc. Category controls remain separate.

Up to twelve independent NVDA audio streams play at once: long navigation and typing recordings do not interrupt other sounds. Playback has a bounded queue to avoid accumulating sounds after focus moves. Keyboard Sounds remains mutually exclusive with Navigation and Typing. As of v0.14, every sound preset is editable under globalPlugins/soundThemes/effects/; export your custom WAVs before upgrading.

Using and editing sound themes

Customize sound effects for focus, typing, navigation, object roles and states, Windows lock and unlock, plus many other NVDA events.

Set up

  1. After installing the add-on, restart NVDA.
  2. Open NVDA menu, Tools, Sound Themes settings...
  3. Select navigation and typing sound themes independently, then customize volume and event options.
  4. Choose Manage sound themes and then its Navigation or Typing tab. Edit any selected theme directly, then assign WAV files to individual events using the keyboard-friendly event list. Each manager lists only that kind of sound event. You may add multiple variations to one event; randomized typing plays WAV files only from the currently selected typing theme.

Sound folders

Included sound packs reside in globalPlugins/soundThemes/effects/navigation/ and globalPlugins/soundThemes/effects/typing/. Each pack folder contains WAV files directly, with no theme.json or manifest. For example, role.button.wav, key.tab.wav, system.lock.wav, and system.secure_enter.wav identify events. Files named key.character.wav and key.character__1.wav provide random typing variations, drawn exclusively from the active typing pack. The included navigation packs are navigation/voiceover (110 recordings), navigation/default (85) and navigation/talkback (39); the typing/classic-typewriter pack now includes six original character variations plus a real carriage bell. Eleven more typing themes were added in version 0.9. The earlier code-only ZIP did not include audio; a newer genuine sound-bearing ScreenReaderSounds ZIP has since been imported, as described above. No synthesized WAVs are bundled. Custom packs also use the installed add-on's globalPlugins/soundThemes/effects/ directory. Existing v0.1.0 personal themes are copied into the two new categories without removing the original files. Personal v0.2.0 packs are converted with backups of the original folders.

Shortcuts

  • NVDA+Alt+N: toggle navigation effects, twice to toggle typing effects.
  • NVDA+Alt+O: toggle all sound effects.
  • NVDA+Alt+Z and NVDA+Alt+X: cycle between navigation themes only.

Notes

The old folder-import button was removed; use Import theme ZIP or Replace WAV to customize any pack. Custom WAVs live inside the installed add-on and should be exported before updating the add-on. Use PCM WAV audio. Lock and unlock effects use NVDA's session-state events; secure-desktop transitions use a separate listener when the running NVDA version provides one. Keyboard context is captured through NVDA's existing raw-key hook, retaining the useful pressed-key tracking provided by the old k library without installing an additional global keyboard hook. Running any add-on on Windows secure screens must be explicitly permitted through NVDA's system-wide configuration feature and entails security risks.

This preview has passed the offline regression suite but has not been verified end-to-end on Windows NVDA 2026. The first 21 WAVs came from the original navSounds publisher; the new audio-bearing ScreenReaderSounds ZIP provided the additional recordings, and seven Kliq themes were supplied by the user. The packaged total is now 1,398 genuine WAVs. Kliq recordings are MIT licensed (doc/KLIQ_LICENSE.txt) and Bucklespring is GPL v2 (doc/BUCKLESPRING_LICENSE.txt).
