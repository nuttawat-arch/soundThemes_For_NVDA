Sound Themes for NVDA

Version 0.17.5. Sound Themes lets you choose, hear and customize sound effects for navigating Windows, typing and using individual keyboard keys. The add-on works without the NVDA Add-on Store.

1. Open settings

  1. Press NVDA+N to open the NVDA menu.
  2. Choose Tools, then Sound Themes settings....
  3. Choose the sound themes, enable the options you need and set the volume.
  4. Choose OK to save settings or Cancel to leave without saving these options. Press Escape to cancel the settings window.

The settings window is separate from NVDA Preferences. When it opens, keyboard focus starts at Navigation sound theme, the first setting, instead of OK. You can switch among its controls with Tab and Shift+Tab. Use Apply to activate and save changes while keeping the dialog open, OK to save and close, or Cancel to discard changes since the last Apply.

2. Choose how sounds play

  • Navigation sounds: feedback for focus changes, controls such as buttons and check boxes, lists, selection and browser Browse Mode.
  • Typing sounds: feedback when typing in a text field, including Space, Enter and Backspace when detected.
  • Keyboard sounds: physical press/release feedback for individual keys, including modifier and special keys when Windows reports them.

You can use Navigation and Typing together. Turning on Keyboard Sounds turns both of those off; turning either one back on disables Keyboard Sounds. System sounds, including lock and unlock, have a separate option. The global Enable Sound Themes option switches all effects on or off.

Navigation effects follow actual NVDA events. Simply pressing an arrow or Tab key does not automatically play a navigation cue when no focus or cursor movement is reported. Not every hardware Fn or media key reaches NVDA.

Typing and Keyboard Sounds have a separate bounded playback queue. This helps them play during rapid focus changes, but under extreme load some sounds can still be skipped rather than interrupting NVDA. The add-on does not record your typed characters.

3. Manage sound themes

  1. Open Manage sound themes... from the settings window.
  2. Select the Navigation, Typing or Keyboard Sounds tab with Ctrl+Tab or the normal notebook navigation keys.
  3. Move through the available themes using the arrow keys. A sample of the selected theme plays automatically. Press Space on a theme name to replay its sample immediately; there is no need to leave the list.
  4. Choose Use this theme to activate it. Choose Create (Alt+C) to make a new theme based on the selected one, or use the other buttons to edit, rename, delete, import or export themes.
  5. Press Escape anywhere in the manager to close it. You do not need to Tab to the Close button.

All included themes can be customized or removed. Some older third-party themes may use a copy-first format; follow the prompt if it appears. Exporting a theme creates a ZIP file that you can import later.

4. Customize individual sounds

  1. In the theme manager, select a theme and choose Edit sounds....
  2. Move through the single alphabetical list of sounds with the arrow keys. Each entry previews its assigned sound when available. Press Space on the selected sound name to play it again immediately without moving to the Preview button. Names remain short and compatible with classic sound packs: for example checkbox, editabletext and typekey.
  3. Read the description below the list to learn when the sound plays. You can disable spoken descriptions if you prefer quieter browsing.
  4. Choose Choose sound file... to assign a WAV file, Preview to listen, or Remove assignment to clear the item. Navigation and Typing also allow multiple sound variations where supported.
  5. Choose Done to keep your edits. If you choose Cancel or press Escape after making changes, a confirmation asks whether to discard them: No (the default) returns to editing, while Yes discards this session's changes.

The installed sound folders are inside globalPlugins/soundThemes/effects/. The add-on no longer creates a separate sound directory at the root of NVDA user settings.

5. Keyboard sounds

In the Keyboard Sounds tab, choose how the selected theme plays:

  • Two layers: one WAV for the press and a different WAV for the release.
  • One layer: one WAV already contains the complete press-and-release effect; it plays once when the key is pressed and does not play again on release.

In the keyboard editor you can assign and preview release sounds separately when using two layers. There is also a key-capture field: focus it and press a key to locate its sound. Press Tab to move out of this field and Escape to cancel the editor. To customize the Tab key itself, select Tab from the alphabetical sound list. Held-key repeats and duplicate modifier reports are filtered.

6. Keyboard shortcuts

  • NVDA+Alt+N: toggle Navigation Sounds; press twice quickly to toggle Typing Sounds.
  • NVDA+Alt+O: toggle all Sound Themes effects.
  • NVDA+Alt+Z / NVDA+Alt+X: choose the previous or next Navigation theme.
  • Escape: close the theme manager; cancel and roll back changes in the sound editor.

You can review and change NVDA shortcuts through NVDA's Input Gestures dialog.

7. Updates and backups

In Sound Themes settings, turn on Automatically check for updates (Alt+A). No time interval needs configuring. Sound Themes checks 15 seconds after NVDA starts and then every 30 minutes while NVDA is running, without requiring a restart. You may also choose Check for updates now (Alt+U). Changes to this option take effect when you press Apply or OK. GitHub does not send push notifications to the add-on, so detection may take up to 30 minutes.

When a newer stable GitHub Release is ready, an accessible window opens automatically with a read-only What's new text box showing the developer's release notes. Use Update now, Later or Skip this version. Pressing Escape is the same as Later. You will be notified automatically only once per version; use Check for updates now to open it again. An update is not installed without approval, and NVDA must restart after installation, though detecting updates does not require a restart. A version still being published does not appear as available until its installer is ready.

Your customized WAVs are now preserved during normal updates through NVDA, including files you directly modified in a supplied sound theme without making a copy. The installer moves your personalized WAVs into the new version before switching. All active audio stays inside the installed add-on. Future releases can distinguish modified recordings from untouched factory sounds so the latter may receive improvements. The first upgrade from an older version conservatively keeps its existing WAVs. Exporting a ZIP is optional extra protection; do it before uninstalling the add-on or manually replacing its whole folder, since those operations cannot use the automatic upgrade transfer.

8. Troubleshooting and limitations

Typing Sounds now plays in editable text fields by default, including after upgrading older settings. If you explicitly uncheck “Only play typing sounds in text fields”, it may also sound during Desktop quick-search. Keyboard Sounds is a separate mode that intentionally makes a sound for every physical keypress, including on the Desktop.

  • If Tools → Sound Themes settings... does not open a window, open NVDA menu → Tools → View log immediately afterwards. Look for a line beginning Sound Themes: could not open the settings window and send the related traceback to the developer. New builds also show an error message instead of silently failing.
  • If you hear two sounds, check whether another keyboard or navigation sound add-on or a Windows accessibility sound is also active.
  • If a theme is silent, check Enable Sound Themes, the active theme, volume, and whether the relevant Navigation, Typing or Keyboard mode is on.
  • If individual sounds disappear intermittently, check other sound add-ons and the NVDA audio output device. If the problem continues, send the NVDA log and a description of when the audio goes missing to the developer.
  • A sound assigned to an older event name may not have a current NVDA trigger. Its event description says when this is known.
  • Some keys, secure desktop events and browser control notifications depend on Windows, the application and the NVDA version.

For more information or to report an issue, visit the Sound Themes project on GitHub.
