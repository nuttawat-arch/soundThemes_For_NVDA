คู่มือ Sound Themes สำหรับ NVDA

เวอร์ชัน 0.17.5 ส่วนเสริมสำหรับเลือก ฟัง และปรับแต่งเสียงนำทาง เสียงพิมพ์ และเสียงกดหรือปล่อยปุ่มคีย์บอร์ด สามารถติดตั้งและอัปเดตจาก GitHub โดยไม่ต้องผ่าน NVDA Add-on Store

สารบัญ

  1. เปิดหน้าตั้งค่า
  2. เลือกรูปแบบเสียง
  3. จัดการชุดเสียง
  4. แก้ไขเสียงแต่ละรายการ
  5. เสียงคีย์บอร์ด
  6. ปุ่มลัด
  7. อัปเดตและสำรองข้อมูล
  8. ปัญหาที่พบบ่อย

1. เปิดหน้าตั้งค่า

  1. กด NVDA+N เพื่อเปิดเมนู NVDA
  2. เข้า เครื่องมือ (Tools) แล้วเลือก ตั้งค่า Sound Themes...
  3. เลือกชุดเสียงที่ต้องการ เปิดตัวเลือก และปรับความดัง
  4. กด ตกลง (OK) เพื่อบันทึก หรือ ยกเลิก (Cancel) เพื่อออกโดยไม่บันทึกค่าตัวเลือก กด Escape เพื่อยกเลิกหน้าต่างตั้งค่าได้เช่นกัน

หน้าตั้งค่า Sound Themes เปิดเป็นหน้าต่างของส่วนเสริมโดยตรง ไม่ได้ซ่อนอยู่ในเมนูการตั้งค่า NVDA เมื่อเปิดหน้าต่าง โฟกัสจะเริ่มที่ช่อง Navigation sound theme ซึ่งเป็นตัวเลือกแรก แทนการไปอยู่ที่ปุ่ม OK ใช้ Tab และ Shift+Tab เพื่อเลื่อนระหว่างรายการได้ กด Apply เพื่อบันทึกและใช้ค่าทันทีโดยไม่ปิดหน้าต่าง กด OK เพื่อบันทึกและปิด หรือ Cancel เพื่อยกเลิกการเปลี่ยนแปลงที่ยังไม่ได้กด Apply

2. เลือกรูปแบบเสียง

  • เสียงนำทาง: เล่นเมื่อโฟกัสย้ายไปยังส่วนควบคุม เช่น ปุ่ม ช่องทำเครื่องหมาย รายการ หัวข้อบนเว็บ และเมื่อเลื่อนใน Browse Mode
  • เสียงพิมพ์: เล่นขณะพิมพ์ในช่องข้อความ รวมถึง Space, Enter และ Backspace เมื่อ NVDA ตรวจพบเหตุการณ์
  • เสียงคีย์บอร์ด: เล่นตามปุ่มจริงที่กดหรือปล่อย เช่น Shift, Ctrl, Alt, Enter, F1–F12 และ Numpad เมื่อ Windows ส่งเหตุการณ์นั้นให้ NVDA

เสียงนำทางและเสียงพิมพ์สามารถเปิดพร้อมกันได้ แต่เมื่อเปิดเสียงคีย์บอร์ด ระบบจะปิดสองหมวดนั้นให้อัตโนมัติ หากเปิดเสียงนำทางหรือเสียงพิมพ์อีกครั้ง ระบบจะปิดเสียงคีย์บอร์ด ส่วนเสียงระบบ เช่น ล็อกและปลดล็อกหน้าจอ สามารถตั้งแยกได้

เสียงนำทางอาศัยการเปลี่ยนโฟกัสหรือเคอร์เซอร์จริง การกด Tab หรือลูกศรไม่ได้รับประกันว่าจะเกิดเสียงทุกครั้ง และปุ่ม Fn บางรุ่นอาจไม่ถูกส่งถึง NVDA

3. จัดการชุดเสียง

  1. ในหน้าตั้งค่า กด จัดการชุดเสียง...
  2. เลือกแท็บ เสียงนำทาง, เสียงพิมพ์ หรือ เสียงคีย์บอร์ด สามารถใช้ Ctrl+Tab หรือปุ่มนำทางแท็บตามปกติ
  3. กดลูกศรขึ้นหรือลงในรายการชุดเสียงเพื่อฟังตัวอย่างโดยไม่ต้องเปลี่ยนชุดที่เปิดใช้งาน กด Space ที่ชื่อชุดเสียงเพื่อเล่นตัวอย่างซ้ำทันที โดยไม่ต้องออกจากรายการ
  4. เลือก ใช้ชุดเสียงนี้ เพื่อเปิดใช้ หรือเลือก สร้าง (Alt+C) เพื่อสร้างชุดเสียงใหม่จากชุดที่เลือก และใช้ปุ่มอื่นเพื่อแก้ไข เปลี่ยนชื่อ ลบ นำเข้า หรือส่งออกชุดเสียง
  5. กด Escape เพื่อปิดหน้าจัดการได้ทันที ไม่ต้องกด Tab ไปหาปุ่มปิด

ชุดเสียงที่ติดตั้งมาพร้อมส่วนเสริมสามารถแก้ไขหรือนำออกได้ ชุดเสียงจากโครงสร้างรุ่นเก่าบางแบบอาจต้องคัดลอกก่อนแก้ไขตามที่โปรแกรมแจ้ง การส่งออกจะได้ไฟล์ ZIP ซึ่งสามารถนำกลับเข้ามาภายหลัง

4. แก้ไขเสียงแต่ละรายการ

  1. เลือกชุดเสียง แล้วกด แก้ไขเสียง...
  2. เลื่อนรายการเสียงที่เรียงตามตัวอักษรจากบนลงล่าง เสียงที่กำหนดไว้จะเล่นตัวอย่างอัตโนมัติ กด Space ที่ชื่อเสียงที่เลือกเพื่อเล่นซ้ำได้ทันที ไม่ต้องกด Tab ไปหาปุ่มฟังตัวอย่าง ชื่อรายการสั้นและคงรูปแบบเดิม เช่น checkbox, editabletext และ typekey เพื่อรองรับชุดเสียงเก่า
  3. อ่านข้อความอธิบายใต้รายการเพื่อทราบว่าเสียงเกิดขึ้นเมื่อใด หากไม่ต้องการฟังคำอธิบายขณะเลื่อนรายการ สามารถปิดตัวเลือกอ่านคำอธิบายได้
  4. กด เลือกไฟล์เสียง... เพื่อนำ WAV มากำหนด กด ฟังตัวอย่าง เพื่อตรวจเสียง หรือ นำเสียงที่กำหนดออก หากต้องการลบการเชื่อมโยง ในบางหมวดเพิ่มเสียงทางเลือกหลายไฟล์ได้
  5. กด เสร็จสิ้น เพื่อเก็บการแก้ไข หากกด ยกเลิก หรือ Escape หลังแก้ไขเสียงแล้ว ระบบจะแสดงหน้าต่างยืนยัน ให้เลือก No (ค่าเริ่มต้น) เพื่อแก้ไขต่อ หรือ Yes เพื่อทิ้งการแก้ไขรอบนี้

ชุดเสียงทั้งหมดเก็บไว้ภายในตัวส่วนเสริมที่ globalPlugins/soundThemes/effects/ และไม่สร้างโฟลเดอร์เก็บเสียงซ้ำที่ไดเรกทอรีตั้งค่าหลักของ NVDA

5. เสียงคีย์บอร์ด

ในแท็บเสียงคีย์บอร์ด แต่ละชุดเลือกการเล่นได้สองรูปแบบ:

  • สองเลเยอร์: มีไฟล์เสียงกดและเสียงปล่อยแยกกัน
  • เลเยอร์เดียว: ไฟล์เดียวบันทึกเสียงกดและเสียงปล่อยไว้ครบ เล่นครั้งเดียวเมื่อกดและไม่เล่นซ้ำตอนปล่อย

หน้าแก้ไขเสียงคีย์บอร์ดมีปุ่มกำหนดและฟังเสียงปล่อยแยกต่างหาก มีช่องให้กดปุ่มจริงเพื่อค้นหารายการเสียงนั้น กด Tab เพื่อออกจากช่องนี้ กด Escape เพื่อยกเลิก หากต้องการตั้งเสียงของปุ่ม Tab เอง ให้เลือก Tab จากรายการเสียงโดยตรง ระบบลดการเล่นเสียงซ้ำเมื่อกดปุ่มค้างและเมื่อ Windows รายงานปุ่ม Shift/Ctrl/Alt ซ้ำหลายรูปแบบ

6. ปุ่มลัด

  • NVDA+Alt+N: เปิด/ปิดเสียงนำทาง กดสองครั้งอย่างรวดเร็วเพื่อเปิด/ปิดเสียงพิมพ์
  • NVDA+Alt+O: เปิด/ปิดเสียงทั้งหมดของ Sound Themes
  • NVDA+Alt+Z / NVDA+Alt+X: เลือกชุดเสียงนำทางก่อนหน้า/ถัดไป
  • Escape: ปิดหน้าจัดการชุดเสียง หรือยกเลิกการแก้ไขในหน้าแก้ไขเสียง

ดูหรือแก้ปุ่มลัดได้ในหน้าตั้งค่าท่าทางการป้อนข้อมูล (Input Gestures) ของ NVDA

7. อัปเดตและสำรองข้อมูล

เปิด ตรวจหาอัปเดตอัตโนมัติ (Alt+A) โดยไม่ต้องเลือกช่วงเวลา ส่วนเสริมจะตรวจครั้งแรกหลังเปิด NVDA ประมาณ 15 วินาที และตรวจซ้ำทุก 30 นาทีขณะ NVDA ทำงาน ไม่ต้องเริ่ม NVDA ใหม่เพื่อให้ตรวจพบรุ่นใหม่ สามารถกด ตรวจหาอัปเดตตอนนี้ (Alt+U) ได้ทุกเมื่อ การเปลี่ยนตัวเลือกมีผลเมื่อกด Apply หรือ OK เนื่องจาก GitHub ไม่ได้ส่งการแจ้งเตือนตรงเข้ามาที่ส่วนเสริม การตรวจพบจึงอาจใช้เวลาสูงสุดประมาณ 30 นาที

เมื่อ GitHub เผยแพร่รุ่นใหม่พร้อมไฟล์ติดตั้ง จะเปิดหน้าต่างอัตโนมัติพร้อมช่องข้อความ มีอะไรใหม่ ให้อ่านรายละเอียดด้วย NVDA เลือก อัปเดตตอนนี้, ไว้ภายหลัง หรือ ข้ามรุ่นนี้ ได้ กด Escape เท่ากับไว้ภายหลัง ส่วนเสริมจะแจ้งอัตโนมัติเพียงครั้งเดียวต่อรุ่น แต่สามารถกดตรวจเองเพื่อเปิดรายละเอียดซ้ำได้ การติดตั้งยังต้องได้รับคำยืนยันและต้องเริ่ม NVDA ใหม่หลังติดตั้ง ไม่มีการติดตั้งเองโดยพลการ

ระบบรักษาไฟล์ WAV ที่ผู้ใช้ปรับแต่งระหว่างอัปเดตส่วนเสริมผ่าน NVDA ตามปกติแล้ว รวมถึงไฟล์ที่แก้ในชุดเสียงมาตรฐานโดยไม่ได้สร้างชุดใหม่ ขั้นตอนติดตั้งจะย้ายเสียงที่ปรับแต่งจากรุ่นเก่าไปยังรุ่นใหม่ก่อนสลับเวอร์ชัน และไฟล์เสียงที่ใช้งานยังอยู่ภายในโฟลเดอร์ส่วนเสริมเหมือนเดิม รุ่นถัดไปสามารถแยกเสียงที่แก้แล้วออกจากเสียงต้นฉบับที่ยังไม่ได้แก้ เพื่อรับการปรับปรุงของเสียงมาตรฐานโดยไม่ทับเสียงส่วนตัว ส่วนการอัปเดตจากรุ่นเก่าที่ไม่มีข้อมูลเปรียบเทียบจะรักษา WAV เดิมทั้งหมดก่อน การส่งออกชุดเสียงเป็น ZIP เป็นการสำรองเพิ่มเติมตามต้องการ แต่ควรทำก่อนถอนการติดตั้งหรือแทนที่โฟลเดอร์ด้วยตนเอง เพราะกรณีเหล่านั้นไม่ได้ผ่านระบบย้ายข้อมูลตอนอัปเดต

8. ปัญหาที่พบบ่อยและข้อจำกัด

เสียงพิมพ์และเสียงคีย์บอร์ดมีคิวรอเล่นแยกจากเสียงนำทางเพื่อลดปัญหาเสียงปุ่มถูกเบียด เมื่อระบบมีงานหนาแน่นมากก็อาจข้ามเสียงบางรายการได้ ส่วนเสริมไม่ได้บันทึกข้อความที่พิมพ์

โหมดเสียงพิมพ์ตั้งค่าเริ่มต้นให้เล่นเมื่อพิมพ์ในช่องข้อความจริงเท่านั้น แม้อัปเกรดจากรุ่นเก่า หากปิดตัวเลือก “เล่นเสียงพิมพ์เฉพาะในช่องข้อความ” อาจมีเสียงขณะพิมพ์เพื่อค้นหารายการบนเดสก์ท็อปได้ ส่วนโหมดเสียงคีย์บอร์ดเป็นอีกโหมดหนึ่งซึ่งตั้งใจให้เล่นเสียงปุ่มจริงทั่วระบบรวมถึงเดสก์ท็อป

  • หากเลือก เครื่องมือ → ตั้งค่า Sound Themes... แล้วหน้าต่างไม่เปิด ให้เข้า เมนู NVDA → เครื่องมือ → ดูบันทึก (View log) ทันที จากนั้นค้นหา Sound Themes: could not open the settings window และส่งข้อความผิดพลาดบริเวณนั้นให้ผู้พัฒนา รุ่นใหม่จะมีข้อความแจ้งเมื่อเปิดหน้าต่างไม่ได้ แทนที่จะเงียบไปเฉย ๆ
  • หากได้ยินเสียงซ้อน ตรวจสอบส่วนเสริมเสียงคีย์บอร์ด/เสียงนำทางอื่น รวมถึงเสียงจาก Windows ที่อาจเปิดพร้อมกัน
  • หากไม่มีเสียง ตรวจตัวเลือกเปิด Sound Themes หมวดเสียงที่ใช้งาน ชุดเสียงปัจจุบัน และระดับความดัง
  • หากเสียงหายเป็นบางครั้ง ให้ตรวจสอบอุปกรณ์เอาต์พุตเสียงของ NVDA และส่วนเสริมเสียงตัวอื่น หากยังพบปัญหา ให้ส่งบันทึก NVDA พร้อมแจ้งว่าเสียงหายระหว่างใช้งานลักษณะใด
  • บางรายการมาจากชุดเสียงรุ่นเก่าและอาจยังไม่มีเหตุการณ์อัตโนมัติใน NVDA ปัจจุบัน อ่านคำอธิบายของรายการนั้นประกอบ
  • ปุ่มพิเศษ หน้าจอปลอดภัย และเสียงบางชนิดในเบราว์เซอร์ขึ้นอยู่กับ Windows แอป และ NVDA ที่ใช้
