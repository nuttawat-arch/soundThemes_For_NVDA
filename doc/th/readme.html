Sound Themes for NVDA — ชุดเสียงสำหรับ NVDA

รุ่น 0.12.0: แก้เสียงปุ่ม ลิงก์ หัวเรื่อง และส่วนควบคุมภายในหน้าเว็บเมื่อใช้ Browse Mode

ตรวจสอบแล้วพบว่าทั้งชุด Navigation Default และ VoiceOver มีไฟล์ WAV จริงของปุ่ม ลิงก์ หัวเรื่อง ช่องทำเครื่องหมาย ปุ่มตัวเลือก และเมนูอยู่แล้ว ปัญหาคือการรับอีเวนต์: เมื่อใช้ NVDA Browse Mode เคอร์เซอร์เสมือนเลื่อนไปตามหน้าเว็บได้โดยไม่เปลี่ยนโฟกัสคีย์บอร์ด จึงไม่มีเสียงบทบาทจากอีเวนต์โฟกัสตามปกติ นอกจากนี้เส้นทางที่พยายามเชื่อมอีเวนต์ Browse Mode อ้างอิงผิดตำแหน่ง และโค้ดสำรองการค้นหาด้วยตัวอักษรเรียกฟังก์ชันเลื่อนเคอร์เซอร์ผิดตัวในบางกรณี

รุ่นนี้แก้ต้นเหตุทั้งสอง พร้อมปรับระบบติดตามการเคลื่อนที่จริงของเคอร์เซอร์ Browse Mode ให้เลือกเสียงตามชนิดวัตถุที่พบ เช่น กด B ไปปุ่ม K ไปลิงก์ H ไปหัวเรื่อง หรือเลื่อนด้วยลูกศรผ่านส่วนควบคุมบนเว็บ หากข้อความอยู่ภายในลิงก์หรือปุ่ม จะเลือกเสียงของลิงก์หรือปุ่มนั้นก่อน แทนการเล่นเสียงข้อความทั่วไป และหากตรวจบทบาทไม่ได้จึงใช้เสียงเลื่อนเคอร์เซอร์เดิม เล่นเพียงหนึ่งเสียงสำหรับการเคลื่อนที่หนึ่งครั้ง ไม่ต้องเพิ่มเสียง WAV ใหม่ ปิด Navigation Sounds แล้วเสียงเหล่านี้จะหยุด โดยไม่กระทบหมวด Keyboard Sounds ควรทดสอบจริงบน NVDA ใน Chrome Firefox และ Edge โดยเปิด Browse Mode

รุ่น 0.11.0: เสียงปุ่มพิมพ์ Enter, Space, Backspace ครอบคลุมขึ้น และลบพรีเซ็ตได้ทุกชุด

ขณะเปิด Typing Sounds หากกำลังพิมพ์ในช่องข้อความที่แก้ไขได้ ส่วนเสริมจะตรวจการกด Enter, Space, Backspace และ Delete ผ่านอีเวนต์กดปุ่มจริงครั้งแรกของ NVDA แม้บางโปรแกรมจะไม่ส่งอีเวนต์อักขระพิมพ์ และป้องกันเสียงซ้ำเมื่ออีเวนต์อักขระตามมาภายหลัง จะเลือกใช้เสียงเฉพาะปุ่มนั้นในชุดที่กำลังใช้อยู่ก่อน หากชุดนั้นไม่มีไฟล์เสียงเฉพาะจะใช้เสียงพิมพ์ตัวอักษรจริงจากชุดเดิมแทน โดยไม่ข้ามชุดและไม่สร้างเสียงจำลอง แพ็กเสียงพิมพ์ 13 ชุดที่มีอยู่จริงนั้น ขาดเสียง Enter แยก 11 ชุด ขาด Space 4 ชุด และขาด Backspace 5 ชุด หมวด Keyboard Sounds ยังใช้การแมปปุ่มจริงแยกต่างหากตามเดิม

ลบปุ่ม Import old sounds folder... ออกแล้ว ตอนนี้กด Delete เพื่อนำพรีเซ็ตใด ๆ ออกจากรายการได้ทั้งหมด แม้จะเป็นชุดที่ติดตั้งมาพร้อมส่วนเสริมหรือเป็นชุดสุดท้ายของหมวด การนำชุดที่ติดมาด้วยออกจะจดจำไว้ในโฟลเดอร์การตั้งค่าของ NVDA เพื่อไม่ให้กลับมาหลังอัปเดต และสามารถนำกลับมาผ่าน Restore removed presets... ได้ ส่วนการลบชุดเสียงส่วนตัวจะลบไฟล์ของชุดนั้นหลังยืนยัน ไม่มีชุดใดถูกบังคับให้คงอยู่หรือสร้างพรีเซ็ตว่างโดยอัตโนมัติ หากต้องการแก้เสียงของชุดที่ติดมา ให้คัดลอกเป็นชุดส่วนตัวก่อน

รุ่น 0.10.0: แก้เสียง Speech feedback paused ซ้อนตอนกด Shift และเพิ่มคำอธิบายแต่ละเสียง

พบสาเหตุจากการทดสอบของผู้ใช้ว่า เมื่อกด Shift เพื่อพักเสียงพูด NVDA จะส่งอีเวนต์พักเสียงพูด ส่วนเสริมเวอร์ชันก่อนจึงเล่นไฟล์ Speech feedback paused เพิ่มจากเสียงปุ่ม Shift จริง โดยอีเวนต์นี้เป็นเสียงระบบ จึงปิด Navigation ก็ยังได้ยิน รุ่นนี้ปิดตัวเลือก Play speech-pause feedback เป็นค่าเริ่มต้น และไม่เล่นอีเวนต์นั้นเมื่อเกิดจากการกด Shift แม้เปิดตัวเลือกไว้ เสียงปุ่ม Shift จริงในหมวด Keyboard Sounds ยังใช้ได้ตามปกติ ไฟล์เสียงพักเสียงพูดยังคงอยู่ให้เลือกและฟังตัวอย่างได้

ในหน้า Edit sounds เมื่อเลื่อนไปยังอีเวนต์ จะมีเสียงตัวอย่างของรายการนั้น พร้อมช่อง Description of selected sound event ซึ่งอธิบายว่าเสียงใช้เมื่อใดและในบริบทใด เช่น รายการไฟล์ใน File Explorer โฟลเดอร์ในแผงต้นไม้ แท็บในเบราว์เซอร์ หรืออีเวนต์ของ NVDA โดยตรง ตัวเลือก Speak the event description when moving through the list เปิดไว้เป็นค่าเริ่มต้น NVDA จะอ่านคำอธิบายเมื่อหยุดเลื่อนชั่วครู่ ไม่สะสมข้อความเก่าขณะเลื่อนเร็ว สามารถกด Tab ไปอ่านข้อความในช่องคำอธิบายได้ ชื่อรายการยังสั้น เช่น C และ Shift ทำให้กดตัวอักษรเพื่อค้นหาได้เหมือนเดิม อีเวนต์เก่าที่ยังไม่มีจังหวะเล่นอัตโนมัติแน่นอนจะมีคำอธิบายระบุไว้

รุ่น 0.9.0: แก้ Shift เล่นเสียงซ้อน และเพิ่มเสียงต้นฉบับที่ยังไม่ครบ

หาก Windows รายงานปุ่ม Shift หนึ่งครั้งด้วยทั้งรหัสทั่วไปและรหัส Shift ซ้าย/ขวา ระบบจะรวมเป็นการกดปุ่มจริงครั้งเดียวและเล่นเพียงเสียงเดียว หลักการนี้ใช้กับ Control และ Alt ด้วย โดยยังแยกการกดปุ่มซ้ายและขวาจริง ๆ ได้ หากมีเสียงซ้อนจากส่วนเสริมอื่นหรือระบบ Windows จะต้องตรวจสอบแยกต่างหาก

นำเสียงจริงจากไฟล์ effects.zip ที่ส่งมาเพิ่มครบ 86 เสียงนำทางและ 61 เสียงพิมพ์ แปลงชื่ออีเวนต์ที่สะกดผิดให้ตรงกับ NVDA เหลือเสียงนำทางที่มีความหมายไม่ซ้ำกัน 85 อีเวนต์ในชุด Default และเติมเสียงที่ VoiceOver เดิมขาดอีก 59 อีเวนต์ โดยรักษาเสียง ScreenReaderSounds เดิมไว้ เพิ่มชุดเสียงพิมพ์ที่เลือกได้อีก 11 ชุด รวมทั้งหมด 706 เสียง WAV จริงใน 23 โฟลเดอร์ชุดเสียง ไม่มีเสียงจำลองหรือ theme.json

รุ่น 0.8.0: เลื่อนรายการแล้วได้ยินตัวอย่างเสียงทันที

เมื่อเลื่อนเลือกรายชื่อชุดเสียง Navigation, Typing หรือ Keyboard ในหน้าตั้งค่าหรือหน้าจัดการ จะได้ยินเสียง WAV จริงจากชุดที่เลือกทันทีโดยยังไม่ต้องเปิดใช้งานชุดนั้น ในหน้าต่างแก้ไขเสียงก็เลื่อนรายการอีเวนต์เพื่อฟังเสียงที่มีได้โดยไม่ต้องกด Preview รายการที่ไม่มีไฟล์จะเงียบโดยไม่รบกวนด้วยหน้าต่างแจ้งเตือน ระบบอ่านไฟล์เสียงอยู่เบื้องหลังและทิ้งคำขอที่ล้าสมัยเมื่อเลื่อนเร็ว

ชื่อรายการเริ่มจากชื่อจริง เช่น Cherry ไม่มีคำว่า Built-in หรือ Custom นำหน้า จึงกด C เพื่อเลือก Cherry ได้ ชื่อบทบาทและสถานะในรายการอีเวนต์ไม่มี Role: หรือ State: นำหน้า ส่วนรายการปุ่ม A ถึง Z และเลข 0 ถึง 9 เริ่มด้วยตัวอักษรหรือตัวเลขนั้นเลย รายการประเภทเสียงยังอยู่ในช่องเลือกหมวดหมู่แยกต่างหาก

ตัวเล่นเสียงรองรับเสียงพร้อมกันสูงสุด 12 ช่องอิสระ เสียงยาวไม่หยุดหรือขวางเสียงที่ตามมา ทั้งเสียงนำทางและเสียงพิมพ์ คิวรอมีขนาดจำกัดเพื่อป้องกันเสียงค้างสะสม กฎเดิมที่เปิด Keyboard Sounds แล้วปิด Navigation และ Typing ยังคงอยู่ตามเดิม ชุดเสียงที่ติดมากับส่วนเสริมอยู่ใน globalPlugins/soundThemes/effects/ ส่วนชุดเสียงส่วนตัวอยู่ในโฟลเดอร์ตั้งค่าของ NVDA เพื่อไม่ให้หายระหว่างอัปเดต

มีสามหมวด ได้แก่ Navigation Sounds และ Typing Sounds ที่เปิดเป็นค่าเริ่มต้น และ Keyboard Sounds ที่ปิดเป็นค่าเริ่มต้น หากเปิด Keyboard Sounds ระบบจะปิดทั้งเสียงนำทางและเสียงพิมพ์ทันที และหากเปิดเสียงนำทางหรือเสียงพิมพ์อีก ระบบจะปิด Keyboard Sounds โดยอัตโนมัติ เสียงระบบและการล็อกหน้าจอแยกเป็นอีกตัวเลือก

ขณะปิด Keyboard Sounds การกด Tab ลูกศร Home End Page Up และ Page Down เพียงอย่างเดียวจะไม่เล่นเสียงปุ่ม เสียงนำทางจะเกิดขึ้นเมื่อ NVDA ตรวจพบการเลื่อนโฟกัส เลื่อนหน้า เปลี่ยนบทบาท หรือการเคลื่อนตำแหน่งจริงเท่านั้น Keyboard Sounds เล่น WAV เฉพาะปุ่มที่กำหนดไว้หนึ่งเสียงต่อหนึ่งปุ่ม ไม่มีเสียงสุ่ม

หน้าตั้งค่ามีปุ่ม Manage sound themes เพียงปุ่มเดียว เปิดหน้าจัดการที่มีสามแท็บ Navigation, Typing และ Keyboard Sounds และมีปุ่ม Open sound folders เพียงปุ่มเดียว สำหรับเปิดโฟลเดอร์หลักของสามหมวด เมื่อเปิดตัวแก้ไข Keyboard ให้ Tab ไปยังช่อง Capture and preview a physical key แล้วกดปุ่มที่ต้องการ เพื่อเลือกอีเวนต์และฟังตัวอย่างทันที การกด Tab/Escape นอกช่องนี้ยังใช้ควบคุมหน้าต่างได้ตามปกติ กด Replace WAV เพื่อเลือกไฟล์จริงจากตำแหน่งใดก็ได้ ระบบจะเปลี่ยนชื่อที่จัดเก็บเป็น keyboard.f7.wav หรือชื่อปุ่มนั้นโดยอัตโนมัติ ไม่ต้องเปลี่ยนชื่อไฟล์ก่อนนำเข้า

โฟลเดอร์หมวดใหม่คือ globalPlugins/soundThemes/effects/keyboard/ สำหรับเสียงที่ติดตั้ง และ soundThemes/effects/keyboard/ ภายใต้การตั้งค่า NVDA สำหรับชุดส่วนตัว ไม่มีไฟล์ theme.json ชุด VoiceOver ยังเก็บเสียงคีย์บอร์ดจาก ScreenReaderSounds จริงสามรายการ คือ Backspace, End และ Shift+Tab และเพิ่มอีก 7 ชุดจาก Kliq ได้แก่ Cherry, DSA, KAT, MT3, OEM, SA และ XDA โดยเลือก KAT เป็นค่าเริ่มต้นสำหรับการติดตั้งใหม่ ปุ่มที่ไม่มีเสียงเฉพาะในแพ็กจะใช้เสียงจริงสำรองจากชุดเดียวกันแบบไม่สุ่ม แป้น Fn และปุ่มปรับแสงบางรุ่นอาจไม่ส่งเหตุการณ์ที่ NVDA ตรวจจับได้

ขณะนี้ได้รับไฟล์ ScreenReaderSounds ชุดใหม่ที่มีไฟล์เสียงจริงแล้ว ระบบนำเสียง WAV และเสียงบทบาทจาก objdata.zip รวมถึง OGG ต้นฉบับที่ถอดรหัสเป็น WAV แล้วมาใช้ รวมทั้งสิ้น 706 ไฟล์ WAV จริง จาก navSounds, ScreenReaderSounds, effects.zip และ Kliq ไม่มีเสียงจำลอง เสียงปล่อยปุ่มที่ไม่ได้ใช้ไม่ถูกนำมาบรรจุ เพื่อลดขนาดส่วนเสริม

แก้ปัญหาการเลื่อนรายการไฟล์ใน File Explorer แล้วไม่มีเสียง: เมื่อรายการมีสถานะ Selected จะเลือกเสียง List item หรือ Tree view item ที่มีอยู่จริง และเลิกต่อเสียงค้างเป็นคิวจนเสียงตามหลังมือ รวมถึงลดการเล่นเสียงซ้ำหรือเสียงยุบต้นไม้ทั้งที่ไม่ได้ยุบจริง

คำแนะนำรุ่นก่อน (ปรับใช้ร่วมกับหมวดใหม่ได้)

ส่วนเสริมชุดเสียงสำหรับการเลื่อนโฟกัส พิมพ์ข้อความ เปิดเมนู เปลี่ยนสถานะองค์ประกอบ และล็อกหรือปลดล็อก Windows

วิธีใช้

  1. ติดตั้งส่วนเสริมแล้วเริ่ม NVDA ใหม่
  2. เปิดเมนู NVDA → การตั้งค่า → ตั้งค่า → Sound Themes
  3. เลือกชุดเสียงนำทางและชุดเสียงพิมพ์แยกจากกัน แล้วปรับระดับความดังตามต้องการ
  4. กด Manage sound themes แล้วเลือกแท็บ Navigation เพื่อจัดการชุดเสียงนำทาง หรือแท็บ Typing เพื่อจัดการชุดเสียงพิมพ์ โดยแท็บทั้งสามสามารถสร้าง คัดลอก แก้ไข นำเข้า และส่งออกชุดเสียงได้ ชุดเสียงที่ติดมากับส่วนเสริมจะต้องคัดลอกเป็นชุดใหม่ก่อนแก้ไข
  5. ในหน้าจอแก้ไข เลือกหมวดหมู่และเหตุการณ์ แล้วกด Replace WAV เพื่อเลือกไฟล์เสียง หรือ Add WAV variation เพื่อเพิ่มเสียงสุ่มหลายแบบ แล้วกด Preview เพื่อฟังตัวอย่าง การสุ่มเสียงพิมพ์จะสุ่มเฉพาะไฟล์ในชุดเสียงพิมพ์ที่กำลังเลือกเท่านั้น ไม่ปะปนกับชุดอื่น

โฟลเดอร์ชุดเสียง

ชุดเสียงที่ติดตั้งพร้อมส่วนเสริมอยู่ใน globalPlugins/soundThemes/effects/navigation/ สำหรับเสียงนำทาง และ globalPlugins/soundThemes/effects/typing/ สำหรับเสียงพิมพ์ ภายในโฟลเดอร์แต่ละชุดมีเฉพาะไฟล์ WAV ไม่ต้องสร้าง theme.json ตัวอย่างเช่น role.button.wav สำหรับปุ่ม key.tab.wav สำหรับ Tab system.lock.wav สำหรับการล็อก และ system.secure_enter.wav สำหรับเข้าสู่หน้าจอปลอดภัย เสียงสุ่มชื่อ key.character.wav และ key.character__1.wav จะสุ่มเฉพาะในชุดเสียงพิมพ์ที่เลือก

ชุดเสียงจริงที่ติดมาด้วย ได้แก่ navigation/voiceover จำนวน 109 อีเวนต์, navigation/default จำนวน 85 อีเวนต์ และ typing/classic-typewriter จำนวน 7 เสียง (รวมเสียงระฆังพิมพ์ดีด) จากชุดเสียงต้นฉบับ ไม่มีเสียงสังเคราะห์ในรุ่นนี้ และชุดเสียงจริงจาก ScreenReaderSounds ฉบับที่ส่งมาใหม่ได้รับการรวมแล้วตามรายละเอียดด้านบน

ชุดเสียงที่ผู้ใช้สร้างเก็บอยู่ภายใต้โฟลเดอร์การตั้งค่า NVDA ที่ soundThemes/effects/navigation/ และ soundThemes/effects/typing/ หากเคยใช้รุ่น 0.1.0 ระบบจะคัดลอกชุดเสียงส่วนตัวเดิมมาแยกหมวด โดยเก็บต้นฉบับไว้ และหากมีชุดเสียงส่วนตัวรุ่น 0.2.0 ระบบจะสำรองโฟลเดอร์เดิมก่อนแปลงเป็นรูปแบบใหม่

ปุ่มลัด

  • NVDA+Alt+N: เปิด/ปิดเสียงนำทาง กดสองครั้งสำหรับเสียงพิมพ์
  • NVDA+Alt+O: เปิด/ปิดเสียงทั้งหมด
  • NVDA+Alt+Z และ NVDA+Alt+X: เปลี่ยนเฉพาะชุดเสียงนำทางย้อนหลังหรือถัดไป โดยไม่เปลี่ยนชุดเสียงพิมพ์

ข้อควรทราบ

รองรับเสียง WAV แบบ PCM โดยจัดเก็บชุดเสียงที่ผู้ใช้สร้างในโฟลเดอร์การตั้งค่า NVDA ปุ่มนำเข้าโฟลเดอร์เสียงเก่าถูกนำออกแล้ว หากต้องการเพิ่มเสียงให้ใช้ Import theme ZIP หรือตั้งค่า Replace WAV ในพรีเซ็ตส่วนตัว ปัจจุบันรวมเสียงจริง 706 ไฟล์จาก navSounds, ScreenReaderSounds, effects.zip และ Kliq ที่นัทส่งมาโดยไม่มีการสร้างเสียงจำลองเพิ่ม ส่วนชุด TalkBack รุ่นอื่นยังไม่ได้รับไฟล์เสียงต้นฉบับแยกต่างหาก

การเล่นเสียงล็อกและปลดล็อกใช้ระบบแจ้งเหตุการณ์รุ่นใหม่ และติดตามการเปลี่ยนหน้าจอปลอดภัยแยกต่างหาก ระบบตรวจปุ่มที่กดใช้ช่องทางตรวจแป้นพิมพ์ของ NVDA โดยนำหลักการติดตามปุ่มจากไลบรารี k มาปรับใช้ ไม่ติดตั้งตัวดักแป้นพิมพ์ทั่วระบบซ้ำกับ NVDA แต่การใช้งานบนหน้าจอปลอดภัย อาจต้องอนุญาตให้ส่วนเสริมทำงานในโปรไฟล์ระบบ ซึ่งต้องพิจารณาความปลอดภัยให้รอบคอบ
